IMAGENES DEL PROYECTO

1) Direccion donde estan las imagenes
- Carpeta principal: public/images/


2) De donde se manejan las imagenes del main
- El main de la home esta en: src/app/(marketing)/page.tsx
- Dentro del <main> se renderiza: <ServicesSection />
- Las imagenes del carrusel del main se definen en:
  src/app/(marketing)/_sections/ServicesSection.tsx
  (const areaCarouselImages)
- El componente que muestra esas imagenes es:
  src/components/shared/PhotoCarousel.tsx
  (usa next/image para renderizar cada src)

Nota:
- En Next.js, una ruta como /images/inst1.jpg apunta al archivo fisico public/images/inst1.jpg.


3) Como centrar manualmente cada foto (mobile y escritorio)
- Archivo a editar:
  src/app/(marketing)/_sections/ServicesSection.tsx
- En cada item de areaCarouselImages podes definir:
  - positionMobile: posicion para mobile/tablet
  - positionDesktop: posicion para escritorio (desde 1024px)
- Formato de valor: "X% Y%" (ejemplo: "50% 52%")

Ejemplo:
{
  src: "/images/det1.jpg",
  alt: "Proceso de car detailing",
  positionMobile: "50% 52%",
  positionDesktop: "50% 46%"
}

Referencia tecnica:
- El carrusel aplica estas posiciones en:
  src/components/shared/PhotoCarousel.tsx
- El responsive de object-position se define en:
  src/app/globals.css
  (clase .carousel-image)


4) De donde se maneja el carrusel (y como pararlo a mano)
- Archivo de control principal:
  src/app/(marketing)/_sections/ServicesSection.tsx
- Constante:
  AREA_CAROUSEL_AUTOPLAY_MS
- Para pararlo manualmente desde codigo:
  poner AREA_CAROUSEL_AUTOPLAY_MS = 0

Detalle:
- Esa constante se pasa a <PhotoCarousel autoPlayMs={AREA_CAROUSEL_AUTOPLAY_MS} />.
- En PhotoCarousel, si autoPlayMs <= 0, no arranca el autoplay.


5) Direccion para manejar la carga de fotos (galeria completa)
- Carpeta de carga:
  public/images/
- Ruta de la pagina:
  /galeria
- Archivo que arma la carga automatica:
  src/lib/gallery/getPublicImages.ts
- Archivo que muestra la galeria agrupada:
  src/app/(marketing)/galeria/page.tsx
- Componente reutilizado para mostrar fotos por grupo:
  src/components/shared/PhotoCarousel.tsx

Regla de agrupacion por nombre de archivo (prefijo):
- car* => Carteleria
- pola* => Polarizados
- pesados* => Maquinaria
- sorri* => Home, Office & Business
- office* => Home, Office & Business
- home* => Home, Office & Business
- det* => Detailing

Ejemplos de nombres validos:
- car010.jpeg
- pola023.jpeg
- pesados016.jpeg
- sorri008.jpeg
- office005.jpeg
- home004.jpeg
- det4.jpg

Nota:
- Si una imagen no coincide con esos prefijos, aparece en el grupo "Otros".

Vista actual de la galeria:
- Se renderiza una card por grupo (ejemplo: Carteleria, Polarizados, etc.).
- Cada card muestra un carrusel con las fotos de esa categoria.
- El carrusel se configura desde:
  src/app/(marketing)/galeria/page.tsx
  (props de PhotoCarousel: autoPlayMs, startDelayMs, showDots, showArrows, showCounter)

Layout actual (2 cards en viewport desktop):
- La grilla usa 2 columnas desde `lg`:
  `lg:grid-cols-2`
- Archivo:
  src/app/(marketing)/galeria/page.tsx

Manejo manual de ancho y alto en galeria:
- Archivo:
  src/app/(marketing)/galeria/page.tsx
- Constantes editables:
  - `GALLERY_GRID_MAX_WIDTH_CLASS` => controla ancho maximo del bloque de cards.
  - `GALLERY_CAROUSEL_HEIGHT_CLASS` => controla alto visible del carrusel en cada card.

Manejo tecnico de alto del carrusel reutilizable:
- Componente:
  src/components/shared/PhotoCarousel.tsx
- Prop nueva:
  `imageContainerClassName`
- Si no se pasa, usa alto por defecto:
  `h-56 sm:h-64`
